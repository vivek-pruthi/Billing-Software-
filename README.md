# Billing Software

A modern, lightweight billing application for retail shops and small businesses. Built with HTML, CSS, and JavaScript, this project helps users create invoices, add products, apply discounts, calculate tax, and print the final bill.

## Live Demo
Open the app locally in your browser after starting a local server.

## Features
- Add products with product name, quantity, and unit price
- Auto-calculate item totals and invoice totals
- Apply discount percentage
- Add sales tax percentage
- Display subtotal, discount, tax, and grand total
- Remove individual products from the bill
- Clear or reset the invoice anytime
- Print the final invoice for customers
- Clean and responsive user interface

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Run Locally
1. Open the project folder.
2. Start a local server:

```bash
python -m http.server 8000
```

3. Open the application in your browser:

```text
http://localhost:8000/
```

## Deployment on GitHub Pages
This project is a static website, so it can be deployed easily on GitHub Pages.

### Steps
1. Push the project to GitHub.
2. Go to your repository on GitHub.
3. Open Settings.
4. Select Pages.
5. Under Source, choose Branch: main and Folder: root.
6. Save.
7. GitHub will generate a live URL for your site.
