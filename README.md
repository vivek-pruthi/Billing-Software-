# Billing Software

A simple and modern billing application built with HTML, CSS, and JavaScript.

## Features
- Add products with name, quantity, and price
- Display bill items in a table
- Remove items from the invoice
- Apply discount percentage
- Add tax percentage
- Calculate subtotal, discount, tax, and final total
- Print invoice
- Reset and clear bill

## Tech Stack
- HTML
- CSS
- JavaScript

## Run Locally
1. Open the project folder.
2. Start a local server:
   ```bash
   python -m http.server 8000
   ```
3. Open in browser:
   ```text
   http://localhost:8000/
   ```

## Project Description
This project is designed for small retail or shop billing needs. It helps users manage product entries, compute totals automatically, apply discounts, and generate a neat invoice-style summary in a web interface.
